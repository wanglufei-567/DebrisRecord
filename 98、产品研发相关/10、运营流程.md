## 运营流程

### 一、运营 SOP 完整流程

```
定位 -> 洞察 -> 准备 -> 引流 -> 承接 -> 信任 -> 转化 -> 交付 -> 留存 -> 促活 -> 复购 -> 裂变 -> 反馈 -> 复盘
```

**各环节说明**

- **定位**：明确目标用户、业务目标、核心卖点
- **洞察**：分析用户需求、痛点、场景和决策链路
- **准备**：准备内容、活动、权益、页面、话术和数据埋点
- **引流**：通过内容、广告、渠道、社群等获取用户
- **承接**：让用户完成关注、注册、进群、咨询、试用等首个动作
- **信任**：通过案例、口碑、专业内容和互动降低决策疑虑
- **转化**：推动购买、下单、预约、签约或提交线索
- **交付**：兑现产品、服务、课程、资料或体验
- **留存**：让用户持续使用、持续关注或留在私域中
- **促活**：唤醒沉默用户，提高互动和参与
- **复购**：推动再次购买、升级套餐或购买延伸服务
- **裂变**：通过转介绍、邀请、分销、拼团带来新用户
- **反馈**：收集咨询、投诉、评价、退款和体验问题
- **复盘**：分析数据、优化素材、话术、流程和责任分工

私域、电商、课程、咨询、SaaS 或本地生活，流程名称会略有变化，但底层都围绕四件事：

- **拉新：让目标用户进来**
- **转化：让用户做出关键决策**
- **留存：让用户持续留下**
- **增长：通过复购、裂变和复盘提升整体效率**
