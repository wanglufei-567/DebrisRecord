## 商机筛选阶段：判断一个机会是否值得进入下一步验证

### 一、阶段定位

**商机筛选不是正式立项，也不是完整售前调研**

它位于更早的位置：

```text
外部机会出现
 -> 商机筛选
 -> 小样本验证 / 售前沟通 / POC / 放弃
```

这个阶段的核心问题不是：

```text
这个机会最终会不会成功
```

而是：

```text
现有信息是否足以支撑我们继续投入验证成本
```

==因此，商机筛选要做的不是直接给出“好 / 不好”的终局判断，而是判断它当前是否值得进入下一步验证==

### 二、商机筛选处理什么对象

商机筛选通常处理的是早期、外部、信息不完整的机会材料，例如：

- 宣传材料
- 产品官网
- **Demo**
- 客户口头描述
- 融资新闻
- 竞品信息
- 合作邀约
- 内部新方向提案

这些材料往往会同时包含**事实**、**推断**、**愿景**和**承诺**，商机筛选的任务就是把它们拆开：

- 判断哪些已经被证明
- 哪些只是值得进一步验证

### 三、商机筛选的 7 个子节点

商机筛选不是一个单点判断，而是一组从对象识别到下一步决策的连续动作

| 子节点          | 核心问题                   | 需要的信息                                            | 关键动作                                           | 输出                   |
| --------------- | -------------------------- | ----------------------------------------------------- | -------------------------------------------------- | ---------------------- |
| 1. 机会来源识别 | 这个机会从哪里来           | 宣传文档、官网、**Demo**、融资信息、客户转介绍、行业事件 | 判断它是技术机会、市场机会、客户需求，还是概念噱头 | 机会来源记录           |
| 2. 对象定位     | 它到底是什么东西           | 产品入口、核心功能、目标用户、使用流程、价格/试用方式 | 用一句话定义对象，不接受泛泛而谈                   | 产品/方案定位          |
| 3. 场景匹配     | 它解决谁的什么问题         | 目标客户、典型用户、使用前后的流程变化                | 判断是否有明确业务场景，而不是只有宏大愿景         | 场景假设               |
| 4. 证据质量评估 | 它证明了什么，没证明什么   | 数据、样本、案例、截图、**Demo**、客户反馈、性能指标    | 区分事实、推断、未知，列出证据缺口                 | 证据缺口清单           |
| 5. 可行性初判   | 技术上、交付上是否可行     | 技术路径、平台适配、失败率、人工介入、边界条件        | 判断“能演示”和“能交付”之间的差距                   | 可行性判断             |
| 6. 商业价值初判 | 值不值得继续投入           | 降本、提效、增收、替代现有方案、客户付费理由          | 判断是否有明确价值杠杆                             | 价值假设               |
| 7. 下一步决策   | 继续、观望、试用，还是放弃 | 前面 6 步的结论                                       | 设计下一步验证动作                                 | **Go / Test / Watch / No-go** |

其中，**证据质量评估**是整个流程的关键门禁，它决定材料是停留在叙事层，还是已经进入可验证判断层

### 四、叙事层级判断

商机材料不一定一开始就有完整证据，有些内容只是在描述方向，有些内容已经能进入验证

可以按下面几个层级判断：

| 层级 | 含义 | 决策价值 |
| --- | --- | --- |
| 愿景叙事 | 描述未来想变成什么 | 只能提供方向感 |
| 方向判断 | 判断某个趋势或问题值得关注 | 可以进入观察 |
| 战略假设 | 说明为什么这个机会值得投入 | 可以进入初步验证 |
| 问题定义 | 明确解决谁的什么问题 | 可以进入方案讨论 |
| 可验证计划 | 有路径、指标、边界和验证动作 | 可以进入执行 |

==**愿景叙事**和**方向判断**不是无价值，它们的问题是停在上层表面，没有落到**可验证**、**可执行**、**可复盘**的层面==

商机筛选要做的事，就是判断一个机会当前处在哪个层级，并决定它是否具备进入下一层级的条件

### 五、不靠谱计划与靠谱计划的对照

一个计划是否靠谱，不取决于它讲得是否宏大，而取决于它有没有把方向落到对象、问题、证据、路径、指标和边界上

```text
靠谱计划 = 方向 + 对象 + 问题 + 证据 + 路径 + 指标 + 边界
```

| 不靠谱计划 | 靠谱计划 |
| --- | --- |
| 只有愿景 | 有明确对象 |
| 只有方向 | 有具体问题 |
| 只有价值宣称 | 有证据链 |
| 只有最终蓝图 | 有阶段路径 |
| 只有增长想象 | 有量化指标 |
| 只讲能做什么 | 也讲不做什么 |
| 回避失败风险 | 主动说明失败边界 |
| 下一步含糊 | 下一步可执行 |

靠谱计划通常有 8 个特征：

| 特征 | 判断问题 |
| --- | --- |
| 对象明确 | 服务谁 |
| 问题具体 | 解决哪个环节的问题 |
| 证据存在 | 为什么相信问题和方案成立 |
| 路径清晰 | 从现在到目标分几步走 |
| 指标可量化 | 做到什么算有效 |
| 边界清楚 | 什么不做，什么暂不承诺 |
| 风险可见 | 主要失败点在哪里 |
| 下一步可执行 | 下一轮具体验证什么 |

### 六、证据质量评估是什么

**证据质量评估**是商机筛选中的关键判断工具

它负责把材料里的内容拆成三类：

| 类型       | 含义                                        | 示例                                 |
| ---------- | ------------------------------------------- | ------------------------------------ |
| 已证明事实 | 有公开资料、数据、样本、**Demo** 或明确陈述支撑 | 官网确实提供产品入口、功能页、客户案例 |
| 分析性推断 | 有一定依据，但还不能当作事实                | 官网宣传注册量，但不披露留存量       |
| 未证明主张 | 材料声称了，但没有证据支撑                  | 效果稳定、能显著降本、能持续变现     |

所以可以把一份材料的状态表达为：

> 这份材料目前主要提供「**愿景叙事**」和「**方向判断**」，但「**证据质量**」不足
>
> 它说明了产品想做什么，却没有充分证明它已经能稳定做到什么，也没有证明客户为什么愿意持续付费

### 七、常见证据缺口

一份商机材料如果缺少下面这些内容，通常就不能直接支撑合作、采购或立项决策：

| 缺口     | 说明                                               | 对应风险 |
| -------- | -------------------------------------------------- | -------- |
| 数据     | 没有成功率、耗时、成本、留存、转化、收入等量化指标 | 无法判断真实效果 |
| 样本     | 没有足够多的真实案例、生成结果或客户项目           | 无法判断稳定性 |
| 技术验证 | 没有说明生成质量、稳定性、失败率、修改能力         | 无法判断可交付性 |
| 商业验证 | 没有证明谁愿意付费、为什么付费、持续付费理由是什么 | 无法判断商业价值 |
| 对照实验 | 没有和传统方案、竞品方案、人工作业方式做比较       | 无法判断优势是否成立 |
| 失败边界 | 没有说明在哪些场景下效果不好、不适合、不应承诺     | 容易过度承诺 |

### 八、用于沟通的判断句式

商机筛选的判断，最好不要停留在“好 / 不好”，而是转成对证据、边界和下一步动作的描述

#### 1. 温和表达

> 我认可它提出的「**问题方向**」，但目前材料主要停留在「**愿景叙事**」
>
> 它已经说明了目标形态，却没有充分证明技术可行性、商业价值和交付边界
>
> 因此现在适合进入商机初筛和小样本验证，不适合直接进入采购、合作或产品立项

#### 2. 专业表达

> 这份材料已经提供了方向判断，但尚未形成完整证据链
>
> 当前缺口主要集中在效果数据、真实样本、可行性验证、商业验证和失败边界
>
> 建议先明确目标用户、核心场景和验证指标，再决定是否进入下一阶段

#### 3. 决策表达

> 当前结论不是直接进入合作或立项，而是进入低成本验证
>
> 下一步应围绕关键假设设计小样本测试，验证对象、问题、效果、成本和边界是否成立

这类表达的好处是：不是情绪化否定对方，而是把对方的叙事推进到可验证问题上

### 九、筛选结论

商机筛选最终不要只输出“好 / 不好”，而是输出下一步动作

| 结论 | 含义 | 下一步 |
| --- | --- | --- |
| **Go** | 证据较充分，值得继续推进 | 进入试用、售前沟通或 **POC** |
| **Test** | 信息不足，但值得低成本验证 | 设计小样本测试 |
| **Watch** | 方向值得关注，但当前证据不足 | 持续观察，等待更多信号 |
| **No-go** | 关键假设不成立，或投入产出明显不匹配 | 暂不投入 |

商机筛选的核心，不是判断一个机会是否伟大，而是判断它是否已经从愿景叙事推进到可验证计划
